## Key Features

- **Bulk PST Migration:** Import single or multiple PST files into Microsoft 365 mailboxes.
- **Primary and Archive Mailbox Support:** Import PST data into Primary Mailboxes, In-Place Archives, and Shared Mailboxes.
- **CSV-Based Mailbox Mapping:** Map multiple PST files to their corresponding Microsoft 365 user accounts using CSV files.
- **Incremental Migration:** Skip previously migrated emails using the Skip Existing Exports option.
- **Modern Authentication:** Connect to Microsoft 365 using OAuth 2.0 or Client ID and Client Secret authentication.
- **Selective Migration:** Apply date filters and select specific mailbox folders for migration.
- **Duplicate Removal:** Identify duplicate emails based on To, From, Subject, Body, and CC fields.
- **Mailbox Preview:** Preview emails, contacts, calendars, tasks, notes, and attachments before migration.
- **Folder Structure Preservation:** Maintain original folder hierarchy, email properties, metadata, and attachments.
- **Custom Folder Creation:** Create a new destination folder in the Microsoft 365 mailbox to organize imported PST data.
- **No Outlook Required:** Migrate PST files without installing Microsoft Outlook or using PowerShell scripts.
- **Multiple PST Support:** Process ANSI and Unicode PST files created by different Outlook versions.
- **Advanced Scanning:** Load corrupted, inaccessible, or locked PST files using the available scan option.

## How to Use

1. Download, install, and launch DRS Softech PST to Office 365 Migration Tool.
2. Select **Select Files** or **Select Folder** to add PST files.
3. Preview mailbox folders, emails, contacts, calendars, and attachments.
4. Select **Save in Email Client** and choose Microsoft 365.
5. Sign in using Modern Authentication or Client ID and Client Secret.
6. Configure mailbox mapping and migration settings.
7. Apply date filters, duplicate detection, and Skip Existing Exports.
8. Click **Start Export** to begin PST migration.
